# AI Cultural Concierge - FREE Setup with Google Gemini ✅

## What's Been Set Up

### ✅ Backend (Node.js)
1. **Google Gemini Service** (`server/src/services/geminiService.js`)
   - `chatWithCulturalConcierge()` - Main AI chat function
   - `extractTravelIntent()` - Parses user messages into structured data
   - `checkGeminiHealth()` - Verifies API connectivity
   - Picks the newest available **Gemini Flash** model automatically (see below)

**Model selection:** the service does not hardcode one model name. Google retires
model aliases (this is why `gemini-pro`, `gemini-2.0-flash` and `gemini-2.5-flash`
now return `404 no longer available`), so it tries an ordered list of candidates,
follows the replacement model named in the 404 response, caches whatever works, and
falls back to asking the API which models the key can use. To pin one, set
`GEMINI_MODEL` in `server/.env`:

```env
GEMINI_MODEL=gemini-3.6-flash
```

2. **API Endpoints** (`server/src/routes/ai.js`)
   - `POST /api/v1/ai/concierge` - Real AI-powered cultural concierge
   - `POST /api/v1/ai/chat` - Legacy endpoint with fallback
   - `GET /api/v1/ai/health` - Check AI service status
   - `GET /api/v1/ai/recommendations` - Scored recommendations

3. **Installed Packages**
   - `@google/generative-ai` ✅ Installed

### ✅ Frontend (React + TypeScript)
1. **API Client** (`frontend/src/lib/api.ts`)
   - `chatWithConcierge()` - Call the AI concierge
   - `checkAIHealth()` - Verify AI is working

2. **Existing UI** (`frontend/src/pages/AiGuidePage.tsx`)
   - Beautiful chat interface already built
   - Works with the new AI backend automatically

## 🐛 Troubleshooting

### ❌ "Gemini API key not configured"
**Solution:**
1. Make sure you added the key to `server/.env`
2. Key should start with `AIza`
3. Restart the backend server: `Ctrl+C` then `npm run dev`

### ❌ "API_KEY_INVALID"
**Solution:**
1. API key is invalid or expired
2. Generate a new key from https://aistudio.google.com/app/apikey
3. Make sure you copied the entire key

### ❌ "Error: 429 Too Many Requests"
**Solution:**
- You've exceeded 15 requests/minute
- Wait 1 minute and try again
- For production, implement rate limiting

### ❌ "models/... is not found for API version v1beta"
**Solution:**
- A model alias was retired by Google. The service now auto-falls-back to a working
  model, so restarting the backend is usually enough.
- To force a specific model, set `GEMINI_MODEL` in `server/.env`.
- To see what your key can reach:
  ```bash
  curl "https://generativelanguage.googleapis.com/v1beta/models?key=$GEMINI_API_KEY"
  ```

### ❌ Backend not starting
**Solution:**
```bash
cd server
npm install  # Reinstall dependencies
npm run dev
```

## 🔄 Switch to OpenAI (Optional)

If you want to use OpenAI instead:

1. Edit `server/src/routes/ai.js`:
```javascript
// Change line 4 from:
import { chatWithCulturalConcierge, extractTravelIntent, checkGeminiHealth } from '../services/geminiService.js';

// To:
import { chatWithCulturalConcierge, extractTravelIntent, checkOpenAIHealth } from '../services/openaiService.js';
```

2. Update health check function calls from `checkGeminiHealth()` to `checkOpenAIHealth()`

3. Add OpenAI key to `.env`:
```env
OPENAI_API_KEY=sk-proj-your-key-here
```
